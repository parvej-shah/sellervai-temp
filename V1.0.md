# Project Requirements V1.0

## Overview
This project is a FastAPI-based backend system that integrates multiple messaging platforms (WhatsApp, Telegram, Facebook Pages, Messenger, Instagram) with AI-powered chat capabilities using LangChain, RAG, and DeekseepAI.

## Technology Stack

### Core Framework
- **FastAPI**: Main web framework
- **OAuth**: Authentication mechanism
- **SQLAlchemy**: ORM for database operations
- **PostgreSQL**: Primary database
- **Alembic**: Database migration tool

### AI & Chat
- **LangChain**: AI orchestration framework
- **RAG (Retrieval-Augmented Generation)**: For context-aware responses
- **DeepseekAI**: LLM provider
- **Streaming Chat**: Real-time chat responses
- **Tool Integration**: AI agent with custom tools

### Messaging Platform Integrations
- WhatsApp Business API
- Telegram Bot API
- Facebook Pages API
- Facebook Messenger API
- Instagram Messaging API
- Instagram Posts and Comments API

## API Endpoints Structure

### 1. Authentication (`/api/auth/`)
- **POST** `/api/auth/login` - User login
- **POST** `/api/auth/logout` - User logout
- **GET** `/api/auth/session` - Returns user profile and session information

### 2. Setup & Configuration (`/api/setup/`)
Endpoints for connecting API keys and webhooks for specific users:

- **POST** `/api/setup/messenger/api-key` - Configure Messenger API key
- **POST** `/api/setup/messenger/webhook` - Configure Messenger webhook
  - Should verify webhook is working correctly before marking as active in database
- **POST** `/api/setup/whatsapp/api-key` - Configure WhatsApp API key
- **POST** `/api/setup/whatsapp/webhook` - Configure WhatsApp webhook
- Similar endpoints for other platforms (Telegram, Instagram, Facebook Pages)

### 3. Chat (`/api/chat/`)
- **POST** `/api/chat/` - Streaming chat endpoint for AI-powered conversations

### 4. Webhooks (`/api/webhooks/<platform-name>/<business-uuid>`)
Platform-specific webhook receivers:
- `/api/webhooks/messenger/<business-uuid>`
- `/api/webhooks/whatsapp/<business-uuid>`
- `/api/webhooks/telegram/<business-uuid>`
- `/api/webhooks/instagram/<business-uuid>`

These endpoints:
- Receive messages, post comments, and other platform events
- Process data using AI agent with custom tools
- Generate responses using database data
- Send responses back to the platform

**Example Use Case**: When a customer asks "How many products do you have?", the AI agent searches the database and replies with the actual product count.

### 5. Business Management (`/api/business/`)
- **GET** `/api/business/` - List all businesses
- **POST** `/api/business/` - Create new business
- **GET** `/api/business/{id}` - Get business details
- **PUT** `/api/business/{id}` - Update business
- **DELETE** `/api/business/{id}` - Delete business

### 6. User Management (`/api/users/`)
- **GET** `/api/users/` - List all users
- **POST** `/api/users/` - Create new user
- **GET** `/api/users/{id}` - Get user details
- **PUT** `/api/users/{id}` - Update user
- **DELETE** `/api/users/{id}` - Delete user

## Data Models

### User Model
- `id`: UUID (Primary Key)
- `name`: String
- `email`: String (Unique)
- `phone_number`: String
- `created_at`: DateTime
- `updated_at`: DateTime
- **Relationship**: One-to-Many with Business

### Business Model
- `id`: UUID (Primary Key)
- `user_id`: UUID (Foreign Key to User)
- `name`: String
- `description`: Text
- `products_items`: JSON (List of products)
- `created_at`: DateTime
- `updated_at`: DateTime
- **Relationships**: 
  - Many-to-One with User
  - One-to-One with Messenger, WhatsApp, Telegram, Instagram, FacebookPages

### Messenger Model
- `id`: UUID (Primary Key)
- `business_id`: UUID (Foreign Key to Business)
- `api_key`: String (Encrypted)
- `added_date`: DateTime
- `webhook_added_date`: DateTime (Nullable)
- `webhook_status`: Enum (verified, pending, failed)
- `status`: Enum (paused, active, inactive)
- `created_at`: DateTime
- `updated_at`: DateTime

### WhatsApp Model
(Similar structure to Messenger Model)

### Telegram Model
(Similar structure to Messenger Model)

### Instagram Model
(Similar structure to Messenger Model)

### FacebookPages Model
(Similar structure to Messenger Model)

## Environment Variables
All sensitive information stored in `.env` file:
- `DATABASE_URL`: PostgreSQL connection string
- `SECRET_KEY`: Application secret key
- `GEMINI_API_KEY`: Google Gemini API key
- `MESSENGER_APP_SECRET`: Facebook Messenger app secret
- `WHATSAPP_API_TOKEN`: WhatsApp Business API token
- `TELEGRAM_BOT_TOKEN`: Telegram bot token
- `INSTAGRAM_API_TOKEN`: Instagram API token
