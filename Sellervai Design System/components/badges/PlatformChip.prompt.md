Compact, brand-tinted chip for a connected messaging platform. For the full connect/disconnect surface with status and actions, use the `Card`/`.sv-platform` pattern instead.

```jsx
<PlatformChip platform="whatsapp" label="Acme Store" />
<PlatformChip platform="messenger" />
<PlatformChip platform="instagram" />
<PlatformChip platform="telegram" />
```

Platforms: `whatsapp` `messenger` `instagram` `telegram`. The icon is tinted with the platform brand token; text stays neutral.
